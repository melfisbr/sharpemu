CUMULATIVE NATIVE-WORKER GUARD
==============================

The current shared SharpEmu repository is also being used for Dragon Ball
FighterZ work. Recent DBFZ packages changed the generic worker cap/prewarm:

V1.8.18 experiment:
  NativeWorkerMaxConcurrent 16 -> 32
  prewarm 8 -> 12

V1.8.19 normalization:
  NativeWorkerMaxConcurrent 32 -> 16
  prewarm 12 -> 8

Therefore V74.0.14 must not copy an older whole NativeWorker source over the
accumulated checkout. Its apply script changes only a literal
NativeWorkerMaxConcurrent declaration into an environment-aware reader and
uses the exact current literal value as the default fallback. The Demon's Souls
runner then explicitly requests 2 only in its own process environment.
