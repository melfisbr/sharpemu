V84.2 corrections:
1. UI-BINK FRAME OWNERSHIP
   For Demon's Souls UI Binks only, every advanced BGRA frame is copied immediately into a presenter-owned persistent byte[] before the asynchronous decoder may recycle its bounded buffer. No per-frame managed allocation occurs after the first size allocation.

2. STICKY SAMPLED PLANE INTEGRITY
   Once a valid full Bluepoint Y/UV sampled pair is observed, its addresses are learned for the active movie. If a later sampled draw exposes only one previously learned plane, that plane is still substituted with the host-decoded image rather than falling through to the raw guest storage/snapshot resource. Storage descriptors are explicitly excluded, so guest decoder compute writes are never intercepted.
