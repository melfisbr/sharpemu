V74.0.75 ANALYSIS

Evidence from the provided Demon's Souls runtime log:
- DRAW_RESOURCE_PHASES: 158.079 ms total, 157.850 ms texture.
- COMPUTE_RESOURCE_PHASES: examples up to 321.134 ms total, 320.849 ms texture.
- SAMPLER_IMAGE_ALIAS reached 175 hits while discarded_mb reached 2799 MB; the same 1024x1024 source arrived as source_kb=16384 before being discarded.
- SLOW_WAIT_PRODUCER repeatedly showed waited_ms > 1 second while producer_state=completed and producer_completed_after_wait=1.
- DEDICATED_WAIT_DRAIN showed Gate waits up to at least 610.506 ms.
- Backpressure occurred with tens of queued works and large retained/payload memory.

Interpretation:
A) Texture source materialization is happening before a sampler-neutral Vulkan image alias decision, causing avoidable copy/detile/allocation work and increasing time under the AGC submit Gate.
B) Real producer completion is already recorded, but several producer paths only pulse the monitor. The actual resumable-DCB drain can therefore be delayed by monitor scheduling/Gate reacquisition.
C) RequestResumableDcbDrain can wake a separate worker even when the current parser already owns Gate, creating a worker whose first action is to block on Gate while the gate owner already has a between-packet drain path.
D) Large texture buffers are allocated zero-filled even though guest-memory reads fully overwrite them before use.

V74.0.75 corrects A-D without changing guest synchronization semantics or increasing queue limits/timeouts.
