V120.0 SOURCE / RUNTIME REVIEW
================================

Measured current state
- V118.0.1: 0.4 FPS, 200 draws/s, CPU 77%, GPU 37%, DeviceLost=0.
- Resident shader fast path is active and fallback-free.
- Descriptor block cache is active and removes almost all repeated allocate/reset calls.
- V119 ReBAR direct globals are active; transfer staging/copy barrier is already bypassed.

Renderer profile
Late Character Creation windows show Draw roughly:
  48.3%, 54.6%, 52.1%, 61.1%, 41.2%, 31.5%, 29.8%, 36.9%, 38.8%, 34.7%.
At 61.1% over 6.8 s / 594 draws that is ~6.99 ms renderer self-time per draw.
The median of the last ten sampled windows is ~3.71 ms/draw.

Concrete source offenders corrected
A) CreateGlobalBufferResource linearly scans _guestBufferAllocations.
   The collection is maintained sorted by BaseAddress and non-overlapping after merge.
   Runtime reaches >150 guest allocations. V120 uses binary search.

B) PrepareGuestBufferAllocations always creates List<(Start,End)> before discovering that
   all bindings are immutable/read-only. Hot draw logs show repeated read-only global shapes.
   V120 fast-returns without transient containers and handles one writable range directly.

C) CreateTranslatedDrawResources creates Dictionary<byte[],VertexBufferResource> and a later
   HashSet<byte[]> even when VertexBuffers.Count is zero. Hot offscreen draw evidence repeatedly
   reports vertex_lengths=[] / vertex_mb=0. V120 removes both containers for 0/1 bindings.

D) Per-texture feedback lookup used LINQ FirstOrDefault with ReferenceEquals. V120 uses the exact
   same reference semantics with a simple loop.

E) Even resident graphics pipeline hits construct structural strings every draw:
   resource layout, target formats, blend layout, vertex layout. V120 canonicalizes strings using
   collision-free value keys; no hash-only shortcut can return the wrong pipeline.

Not changed
All Vulkan resource ownership, byte contents, barriers, submission ordering, guest waits and
physical queue policy remain exactly on the installed baseline.
