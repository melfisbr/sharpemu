V74.0.86.1.5 did not reach build. It failed during post-apply verification for two package-internal reasons:

1. IME source marker version mismatch
   The V86.1.5 checker expected:
     SHARPEMU_V74_0_86_1_5_IME_OSK_BASE64_PAYLOAD
   but payload/ImeDialogExports.cs still contained the previous V86.1.4 marker.
   Cause: the earlier package-version rewrite did not include .cs payload files.

2. Decoded player-title assertion mismatch
   The PowerShell source correctly contains:
     'Enter your player''s name'
   because a literal apostrophe inside a PowerShell single-quoted string is represented by two apostrophes.
   The old post-apply assertion searched the decoded PowerShell source for the display text with only one apostrophe.
