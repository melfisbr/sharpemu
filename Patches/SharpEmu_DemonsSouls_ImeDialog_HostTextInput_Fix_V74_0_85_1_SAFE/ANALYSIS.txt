SharpEmu / Demon's Souls V74.0.85.1 - IME dialog host text input

Observed blocker
- Character Creation reaches the Player Name requirement.
- The game waits for text entry, but SharpEmu shows no software-keyboard/text panel.

Source audit
- Demon's Souls eboot audit contains the libSceImeDialog NIDs resolved by ImeDialogExports.cs.
- Reference source implements sceImeDialogInit by immediately writing a hard-coded default ("Sharp") and setting status FINISHED.
- That is an ABI stub, not an interactive IME lifecycle.

Fix
- Preserve existing SceImeDialogParam offsets already used by SharpEmu: max length +0x24, UTF-16 input buffer +0x28.
- sceImeDialogInit now enters RUNNING and launches an asynchronous host text panel.
- Windows host panel is a hidden PowerShell 5.1 process hosting a WinForms textbox; this adds no WinForms dependency to SharpEmu.Libs and keeps the main emulator executable cross-platform-buildable.
- The UI thread never writes guest memory. The selected text is latched in managed state; sceImeDialogGetStatus/GetResult commit UTF-16LE through the current guest CpuContext, then expose FINISHED.
- Abort/Term invalidate the session and close any pending host panel.
- SHARPEMU_IME_TEXT can provide deterministic text for automated testing; normal operation opens the panel.

No GPU, Bink, AGC, SaveData, controller mapping, or eboot code is modified.
