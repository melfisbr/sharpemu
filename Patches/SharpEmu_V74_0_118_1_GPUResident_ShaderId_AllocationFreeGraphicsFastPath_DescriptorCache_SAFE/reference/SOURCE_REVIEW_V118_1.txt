V118.1 SOURCE REVIEW
====================

- Existing graphics pipeline cache keys construct strings for render-target formats, blend state,
  resource layout and vertex layout.
- V118.0 resident graphics lookup still built render-target/blend/vertex strings before looking up
  its resident pipeline map, so a hot hit did not remove those allocations.
- V118.1 performs a compact lookup first.
- Resource layout is represented by the already-created PipelineLayout handle.
- Scalar raster/depth/topology state is stored exactly.
- Variable render-target/blend/vertex state is hashed allocation-free and exact-compared in the
  selected bucket before reuse.
- The canonical string GraphicsPipelineKey remains the cold/miss authority.

Shader identity improvement:
- same translated SPIR-V byte[] reference uses the immutability contract already assumed by
  `_shaderDigests` and skips SequenceEqual;
- different reference preserves exact SequenceEqual.

No images, buffers, barriers, queue ordering, Pair2 or submission semantics are changed.
