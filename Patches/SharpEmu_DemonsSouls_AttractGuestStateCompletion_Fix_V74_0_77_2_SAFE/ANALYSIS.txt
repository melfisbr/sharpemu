This indicates movie completion is consumed by the game-side Bink/UI state machine.

Fix:
Reuse the existing BinkGuestCompletionShim for RAD-owned attract_movie, only for
Demon’s Souls roots. The guest still opens the real file, but sees NumFrames=1.
The header read that touches NumFrames blocks in WaitForHostPlaybackToFinish,
therefore the guest cannot advance before RAD actually finishes or TAB closes it.
Once host playback ends/skips, the wait is released and the game’s own state
machine can execute the next transition. No host-side logo_intro is fabricated
or pre-queued by this patch.
