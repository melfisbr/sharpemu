V74.0.67.2.8 integration audit

The existing SharpEmu managed bridge already carries the correct Vulkan handle
classes across the ABI:
- VkInstance
- VkPhysicalDevice
- VkDevice
- VkQueue / queue family
- VkCommandBuffer
- color/depth/motion/output VkImage and VkImageView handles

The remaining integration corrections consolidated here are:
1. stop swallowing native NGX extension-query failures as an empty list;
2. use the feature-specific NGX Vulkan extension discovery API;
3. check DLSS feature requirements on the selected physical device;
4. make NGX initialization failure authoritative;
5. serialize NGX calls;
6. consolidate V74.0.67.2.7 source selection so the already-proven temporal
   depth + motion signals can reach the native dispatch path.
