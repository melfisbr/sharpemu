Observed console defect:
[V74.0.10] t={0:F0}s event={1} timeline={2}/{3} ...

Cause:
PowerShell operator precedence applied `-f` to only the second string of a
concatenated format expression.

Observed interruption:
"Deseja finalizar o arquivo em lotes (S/N)? n"

Cause:
Ctrl+C terminated the PowerShell child before the post-runtime analysis and
Compress-Archive phase.

The collector's RedirectStandardOutput/RedirectStandardError and CSV paths are
created before runtime starts. V74.0.10.1 recovers those files directly.

Finalization performance is also improved: stderr.log is read once and the
load-bearing values are extracted with .NET Regex instead of repeated
Where-Object passes across all log lines.
