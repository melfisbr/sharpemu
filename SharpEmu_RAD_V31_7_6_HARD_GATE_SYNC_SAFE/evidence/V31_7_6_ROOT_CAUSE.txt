V72.4.3.2.31.7.6 ROOT CAUSE / DESIGN EVIDENCE
========================================================

Observed V31.7.5:
- First and second RAD videos: correct.
- Third attract_movie: high CPU/GPU, memory growth, video stutter and A/V drift.
- SUMMARY: GUEST_GPU_BACKPRESSURE_MARKERS=0.
- SUMMARY: PEAK_WORKING_MB=7006; PEAK_PRIVATE_MB=12383.
- stderr: Core.Res.TaskManager entered V74 native lane repeatedly after
  bink2.rad_guest_work_throttle_begin for attract_movie.
- stderr: guest images/buffers/pipelines and large texture/DCC work continued.

Code audit:
- V31.7.5 called BinkHostPlaybackAssist.OnMovieFrame/EndMovieSession.
- The accumulated helper lineage exposes those names as compatibility stubs.
- The real GPU throttle key is _activeHostMovieDecoders, changed by
  NotifyHostMovieDecoderStarted/Stopped.
- ShouldThrottleGuestGpu requires SHARPEMU_BINK_THROTTLE_GUEST_GPU == "1".
- V31.7.5 RUN_4 did not set that environment variable.
- V15.1 HostMovieExecutionGateV7243214 provides a ManualResetEventSlim-based
  Begin/End/WaitUntilInactive CPU park.
- V74 NativeWorker already calls BinkHostPlaybackAssist.WaitForGuestCpuPermit.
- V74 Vulkan queue already tests BinkHostPlaybackAssist.ShouldThrottleGuestGpu.

V31.7.6 correction:
1. Ensure the V14 decoder lifecycle hooks own exactly one
   HostMovieExecutionGateV7243214 Begin/End pair (install from the original
   exact V14 anchors only when those hooks are absent).
2. RAD child attach -> NotifyHostMovieDecoderStarted(moviePath).
3. RUN_4 -> SHARPEMU_BINK_THROTTLE_GUEST_GPU=1.
4. ShouldThrottleGuestGpu -> active decoder is tested before boot-complete.
5. RAD release -> NotifyHostMovieDecoderStopped(moviePath).
6. Heartbeat is diagnostic only.
7. Sidecar audio remains 1.0000x; first remove video starvation before changing
   audio timing.

Safety:
- start/stop is exactly-once through _guestThrottleReleased.
- the RAD payload never calls HostMovieExecutionGate Begin/End directly, so it
  cannot double-count the V14/V15 lifecycle gate.
- original source files are backed up and restored on build failure.
- no proprietary RAD/Bink binary or game media is bundled.
